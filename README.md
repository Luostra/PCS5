### Краткий текстовый отчёт 
Для макета приложения "заметки" были созданы страницы:
1.	Экран приветствия (Splash Screen). На экране приветствия располагаются логотип и кнопка начала работы. 
2.	Главный экран (Main Screen). На главном экране отображается список заметок и кнопка добавления заметок, при нажатии на которую осуществляется переход (сопровождается анимацией Smart animate) на экран создания заметки.  
3.	Экран добавления заметки (Add Note Screen). На экране добавления заметки есть два поля ввода, а также кнопки возврата и создания заметки. Обе кнопки ведут на главный экран. Переход на главный экран по кнопке возврата сопровождается анимацией Slide in.

### Краткий анализ
Интерфейс получился минималистичным и интуитивным. В будущем стоит подумать над наполнением.
