## 2. Краткое описание проекта и назначение приложения (содержание аналогично README.md из таблицы).

### **1.1 Назначение приложения**

Мобильное приложение предназначено для персонального хранения, структурирования и редактирования кулинарных рецептов.
Приложение ориентировано на пользователей, желающих вести собственную коллекцию рецептов без использования социальных функций и стороннего контента.

Основная цель — предоставить удобный и безопасный инструмент для:

- создания и редактирования (в т.ч. и удаления) рецептов;
- хранения фотографий блюд;
- классификации рецептов по тематическим папкам;
- быстрого доступа к избранным блюдам.

### **1.2 Используемый стек технологий**

#### **Frontend**

Flutter (Dart) + пакеты SupabaseFlutter, ImagePicker, ImageCropper, EmojiPicker и др.

#### **Backend**

Supabase (Postgres) + Supabase Auth + Supabase Storage + RLS

#### **Архитектура**

**Клиент–серверная архитектура**

1. UI слой (Flutter Widgets)

- отображение элементов интерфейса;
- обработка действий пользователя;
- маршрутизация между экранами.

2. Сервисный слой

- SupabaseService — работа с БД и хранилищем;
- ImageService — получение и обработка изображений.

3. Модельный слой

- классы Folder и Recipe;
- преобразование JSON ↔ модели;
- валидация входных данных.

4. Backend слой (Supabase)

- База данных Postgres;
- Supabase Auth;
- Supabase Storage;
- политики безопасности RLS.

### **1.3 Инструкция по запуску приложения**

Данное мобильное приложение распространяется в виде готового APK-файла через официальный магазин приложений **RuStore** и не требует сборки или дополнительной настройки со стороны пользователя.

#### **Системные требования**

- мобильное устройство под управлением Android версии 8.0 и выше;
- наличие учётной записи RuStore;
- подключение к сети Интернет (для авторизации и синхронизации данных).

#### **Порядок установки и запуска**

1. Откройте приложение **RuStore** на устройстве Android.
2. В строке поиска введите название приложения (либо перейдите по ссылке https://www.rustore.ru/catalog/app/com.example.recipes_app).
3. Перейдите на страницу приложения и нажмите кнопку **«Установить»**.
4. Дождитесь завершения загрузки и установки APK-файла.
5. Запустите приложение с главного экрана устройства.
6. При первом запуске:

   - зарегистрируйтесь, указав адрес электронной почты и пароль,
   - либо выполните вход в существующий аккаунт.

7. После авторизации приложение готово к использованию.

#### **Обновление приложения**

Обновления приложения распространяются через RuStore и устанавливаются стандартными средствами магазина. Пользователю не требуется выполнять дополнительных действий для обновления функциональности.

#### **Удаление приложения**

Для удаления приложения:

1. Перейдите в настройки устройства или в магазин RuStore.
2. Выберите установленное приложение.
3. Нажмите **«Удалить»**.

#### **Примечания**

- Все пользовательские данные хранятся в облаке и доступны после повторной установки приложения при входе в тот же аккаунт.
- Приложение требует доступ к камере и галерее (по запросу пользователя), а также к интернету.

### **7.2 Privacy Policy (Политика конфиденциальности)**

#### 7.2.1 Собираемые данные

Приложение собирает и обрабатывает только минимально необходимые данные:

- адрес электронной почты пользователя;
- пароль (хранится в зашифрованном виде в системе аутентификации);
- пользовательские рецепты и папки;
- изображения блюд, загруженные пользователем.

#### 7.2.2 Хранение данных

- Текстовые данные (рецепты, папки) хранятся в базе данных Supabase (PostgreSQL).
- Изображения хранятся в приватном и защищённом облачном хранилище Supabase Storage.
- Каждый пользователь имеет доступ только к своим данным благодаря политике безопасности RLS.

#### 7.2.3 Использование данных

- Все данные используются исключительно для работы приложения.
- Данные не передаются третьим лицам.
- Приложение не содержит рекламы и аналитических трекеров.

#### 7.2.4 Удаление данных

Пользователь может в любой момент:

- удалить отдельные рецепты и папки;
- удалить изображения;
