### **2.2 Получение геолокации**

Для определения местоположения использовался пакет `geolocator`.
Перед получением координат выполняется проверка доступности сервиса и разрешений.

```dart
final pos = await Geolocator.getCurrentPosition(
  desiredAccuracy: LocationAccuracy.high,
);
```

Полученные координаты преобразуются в адрес при помощи пакета `geocoding`.

---

### **2.3 Работа с сенсорами**

Данные акселерометра и гироскопа считываются в реальном времени с использованием потоков событий:

```dart
accelerometerEvents.listen((event) {
    setState(() {
    _accelerometerValues = [event.x, event.y, event.z];
    _time += 0.1;
    _accelHistory.add(AccelPoint(_time, event.x));
    if (_accelHistory.length > maxPoints) {
        _accelHistory.removeAt(0);
    }
    });
    _checkAlerts();
});
```

```dart
gyroscopeEvents.listen((event) {
    setState(() => _gyroscopeValues = [event.x, event.y, event.z]);
    _checkAlerts();
});
```

Направление движения определяется с помощью компаса:

```dart
FlutterCompass.events?.listen((event) {
  _compass = event.heading;
});
```

---

### **2.4 Построение графика ускорения**

Для визуализации ускорения во времени используется библиотека `fl_chart`.
Значения ускорения сохраняются в список и отображаются на линейном графике:

```dart
LineChartBarData(
  spots: points
      .map((e) => FlSpot(e.time, e.value))
      .toList(),
  isCurved: true,
)
```

График обновляется в режиме реального времени по мере поступления новых данных.

---

### **2.5 Реализация уведомлений**

Для обнаружения резких движений вычисляется модуль ускорения и угловой скорости.
При превышении заданных пороговых значений пользователю выводится уведомление:

```dart
if (magnitude > accelThreshold) {
  _showAlert('⚠ Резкое ускорение!');
}
```

Уведомления реализованы с помощью `SnackBar`.
